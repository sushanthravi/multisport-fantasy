# Multisport Fantasy

## The idea

Most fantasy games revolve around one sport. Multisport Fantasy brings athletes from different sports into **one league and one draft**. We are starting with football (FPL), American football (NFL), and Formula 1, and plan to add more sports as the game grows.

The goal is a simple online game you can play with friends: start a league, draft athletes, follow your team, and see who wins across the season.

## How a league works

1. Create a league with 2–8 teams.
2. Draft in a random snake order: the picking order reverses each round.
3. For the first version, build a 14-athlete team: **6 FPL players, 6 NFL players, and 2 F1 drivers**. Future versions can introduce more sports and league formats.
4. Earn points from what those athletes do after the draft. Each sport contributes equally to the eventual overall score, even though the roster sizes differ.

For example, a strong F1 weekend can help offset a poor FPL gameweek. The idea is to reward good decisions across sports, rather than let the sport with the biggest raw point totals dominate.

## What you can try today

- Browse, search, filter, and sort athletes from all three sports.
- Run a full draft on one device and view every team's roster and pick history.
- Keep a completed league in that browser and download a backup of the teams.
- View a scoring preview for FPL and F1 based on points earned since the league was saved.

**This is an early hosted prototype.** The draft is stored in the browser you use. Friends cannot yet join the same draft from their own devices, and athlete data is updated when a new version of the site is deployed. The NFL data currently helps you draft players but does not include their game results, so the complete three-sport leaderboard is still pending. The scoring formula is a starting point that we can tune after trying the game.

## What comes next

1. **Shared leagues:** Save teams and picks in an online database so friends can join the same draft from different devices.
2. **Live results:** Add NFL game points and regularly update results for all three sports.
3. **A complete leaderboard:** Compare teams as new games and races finish, with scoring that stays understandable and fair across sports.
4. **More sports:** Expand beyond the initial FPL, NFL, and F1 lineup once the core league experience works well.

The current private site is online, but its player data is a snapshot and its drafts belong to one browser. The next hosting milestone is a shared database and an online service that saves league changes and updates scores for everyone.
